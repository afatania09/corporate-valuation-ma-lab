# Valuation methodology and limitations

All demonstration amounts are **fictional GBP millions**. No result is an investment recommendation or professional valuation opinion.

## Market approach
EV = maintainable EBITDA × selected EV/EBITDA multiple. The multiple must be supported by appropriately adjusted comparable-company or transaction evidence. This simple engine does not select multiples automatically.

## Enterprise to equity
Equity = enterprise value − net debt + other equity adjustments. Actual assignments require a documented bridge for debt-like items, surplus assets, working capital, pensions, leases and other claims.

## Income approach
DCF discounts forecast unlevered free cash flow to the firm at WACC. The terminal value uses the Gordon growth formula. WACC must exceed terminal growth. Forecasts and assumptions require independent challenge.

## Fund NAV
Each holding is valued using ordinary equity value multiplied by ownership. This is **only** valid for simple pro-rata ordinary shares. For preferred shares, shareholder loans, ratchets, options, carried interest, liquidation preferences or other economic rights, use an instrument-level waterfall and fair value analysis. Fund-level cash less liabilities produces a simplified NAV.

## LBO
The initial implementation reports gross equity MOIC and annualised IRR for one entry and one exit, without interim cash flows or fees.

## Standards
For real work assess the applicable valuation date, purpose and framework, including IFRS 13, IFRS 3, IPEV guidelines and RICS standards where appropriate. This repository does not claim compliance or independent assurance.

## Data ethics
Use public filings and documented sources for real case studies. Never disclose confidential transaction materials or imply access to non-public information.
